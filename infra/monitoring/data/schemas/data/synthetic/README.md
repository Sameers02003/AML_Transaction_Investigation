# Synthetic data

All data in this project is fictional and generated by `apps/api/scripts/generate.py`.

- `seed`: 200 customers and accounts, 3 institution accounts, 2 newly onboarded "mule" accounts
- `history`: 30 days of ordinary behaviour (used to train the anomaly model)
- `live`: a stream of ordinary events plus a planted layering scenario; writes `labels_live.csv` (git-ignored)

No real customer data is used or stored.
